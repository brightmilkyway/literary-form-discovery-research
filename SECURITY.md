# Security policy

This research repository should never contain live API keys, private datasets, or credentials.

If you believe a secret or private datum has been committed, do **not** open a public issue. Contact
the repository owner through the private contact method on the GitHub profile. Include the affected
path or commit but do not repeat the suspected credential in the message.

The public-release audit scanned all reachable Git blobs and commit messages for common credential
patterns. This reduces risk but is not a guarantee that every possible secret format was detected.
