A reviewer observed that the unit printed as 'sentence 534' in an
earlier run contained three separate speeches.  Diagnosis and fix:

  nltk.sent_tokenize(body) directly      : 764 units, 152 containing an internal line break (UNDER-split)
  split_sentences(body)  [this module]   : 1023 units, 0 under-split, 0 over-split

  Cause of the under-split: the text writes '.”' (period + closing
  CURLY quote) before a blank line, and punkt does not treat '.”' as
  a sentence end, so consecutive speeches were merged.
  Fix: split on blank lines first, then punkt inside each paragraph.

  A first fix attempt normalised curly quotes to straight.  That
  trades the under-split for an OVER-split: punkt treats '?”' as
  mid-sentence (correct) but '?"' as a sentence end, so every
  dialogue tag was cut off its speech:
      “Is it snowing again, Mr Conroy?” asked Lily.   -> 1 part (curly)
      "Is it snowing again, Mr Conroy?" asked Lily.   -> 2 parts (straight)
  The module therefore keeps the original curly quotes.
