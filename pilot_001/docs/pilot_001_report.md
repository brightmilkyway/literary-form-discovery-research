>      （0.479 / 0.764）**。所以那次干预**不是只动内容**。

>      在**保连贯**的级别最高（近义 0.233 / 0.365；SHUF 0.250 / 0.643），
>      在**毁连贯**的最远级最低（0.115 / 0.120）。
>      **→ v15 的结论保留但须削弱**；要彻底分离"词身份"与"连贯性"，
>      需要 **MLM 填空**的改写对照——这是下一轮。

> * **v17（本版）白化检验：各向异性不是内容信号的藏身处**。白化（ZCA）
>   **在另外 14 篇上拟合、在《死者》上评估**：
>   1. 白化**降低**词汇重叠的解释力：r(cos, 共享实词数) **+0.406 → +0.214**
>      （MiniLM）、**+0.531 → +0.162**（bge）。

>   2. top-40 相对配平基线的超出量反而**上升**：+0.184 → **+0.351**、

>   3. **《死者》的低有效维数白化后几乎不变**（31.4 → 30.8；31.8 → 33.2），

>   5. ridge 1e-1 … 1e-6 **五个数量级结论稳定**。

>   1. **连贯的改写仍损伤约一半**：`MLM-top1` **0.044 / 0.016**，

>   3. **在内容摧毁量几乎相同时，语境不合理比词向量远损伤高约 1.4 倍**

## 0. 本轮做了什么（六轮工作）

* 数据：Project Gutenberg 英文正文，85,683 字符 / 455 段 / 15,732 词；seed = 42。
* **三种分析尺度**：句子（**1023**）、段落（455）、150 词组（78）。
* 方法：TextTiling（Hearst 1997，与 NLTK 参考实现逐位一致）、
  NCD（zlib/bz2/lzma）、SBERT；基线：TF-IDF、Jaccard、纯长度相似。
* **修复 A**：NCD 长度混淆 → 0.689 / 0.179 / 0.000。
* **修复 B**：SBERT 截断 25/78（32%）→ **0/184**。
* **裁决 C**（v3）：第二个编码器 + 免校正的互为近邻标准。
* **实验 D**（v4）：受控替换（词汇场消融、移植、词序扰动）+ 同等规模随机对照。
* **裁决 E**（v5）：尺度裁决，三种零假设设计（两种失败，一种成立）。
* **复核 F**（v6/v7）：句子尺度重算 + 分句器修复。
* **审稿修正 G**（v7/v8）：两轮审稿，撤回五项、限定两处证据表述。

## 1. 哪些计算结果引发了此前未明确提出的文学问题？

### 1.1 方法学问题

**(a) 压缩相似性在 150 词尺度上测什么？** NCD 与"压缩长度差"相关 0.689
（解释 47.5% 方差）→ 等词数 0.179 → 残差 0。修复后 NCD↔TF-IDF 由 0.439 升到
**0.688**，NCD↔长度由 0.655 降到 **0.228**。**长度是抑制变量。**
**v7 修正**：句子尺度上该相关为 **0.661**（解释 43.7% 方差）——
与 150 词尺度**相当**；v6 曾称"更严重"（0.728/53.1%），那是错误分句器造成的，
**已撤回**。残差修复在两种尺度都有效（r → 0）。

**(a2) NCD 的对称矩阵是一个假设（v7 新增，审稿意见 2a）。**
`ncd.py` 只算 C(xy) 再镜像。实际压缩器不满足 C(xy) = C(yx)。两个方向独立计算：
`r(正,反) = +0.951`，但 **29.6% 的对变化 > 0.01，top-10 只重合 6/10**。
**对称性已在文档中注明为假设，并同时报告反向拼接结果。**

**(a3) 编码器读的是内容，不是形式（v7 修正，审稿意见 3）。**
v3–v6 曾报告"MiniLM 存在约 0.83 的**形式基线**，所有观察值都在其下方"。
**该解释已撤回**：把实词全部替换为同一个占位词 `thing` 会**人为制造大量相同
词元**，测到的是占位符而非形式。
改用**删除而非替换**的设计（`form-only` = 删实词；`content-only` = 删虚词），
对 120 个随机远距离对：

| 量 | 均值 | sd |
|---|---|---|
| cos_orig | 0.475 | 0.100 |
| cos_form | **0.712** | **0.074** |
| cos_content | 0.413 | 0.106 |

`r(cos_orig, cos_form) = +0.180`；**`r(cos_orig, cos_content) = +0.782`**。
**形式相似度高但几乎不变**（是"两段都是英语散文"的先验，不区分片段）；
**原始余弦的变化由内容驱动**。**结论方向与撤回的说法相反**：
**SBERT 读内容；被长度主导的是 NCD。**

**(b) 三种方法是否在测同一件事？否。** 修复后 SBERT∩NCD top-20 只有 **1 对**；
TextTiling 最强边界处百分位在五种表示下是 49/47/56/51/53%。
**v7 修正**：句子尺度（修正后的 1023 句）上正交性**保持**——词基与句基两种

**(f2) 分句器本身必须经过检验（v7 新增，审稿意见 1）。**
`nltk.sent_tokenize(body)` 直接调用给出 764 个"句子"，其中 **152 个含内部换行**
（是多句块）：原文在段末写 `.”`（句点 + **弯引号**），punkt 不把它当句末，
于是连续三段发言被并成一个单元——**20% 的"句子"不是句子**。
第一次修复（弯引号→直引号）**造成反向错误**：punkt 把 `?"` 当句末，
每个对话标签都被从它的引语上切下来（50 个单元以小写字母开头）。
**正确做法**：先按段落切（原文自带结构），再在段内用 punkt 处理**保留弯引号**
的原文 → **1023 个单元**。三项自动检查（欠切分、过切分、偏移回环）**均未发现错误**
——**措辞限定（v8）**：这只是"在**已定义的**检查规则下未发现错误"，
**不是**"已证明 1023 个边界全部正确"。过切分检查只覆盖预先列出的开头模式，
偏移回环只证明切分能对应回原文。若要把切分精度作为方法学结论，
需另行构建覆盖不同引号、对话标签与标点情形的**人工标注样本**并报告一致性。
**教训：分句器是一个需要验证的组件，不能假定现成工具在文学文本上正确；
同时，验证的结论也不能超出检查规则所能支持的范围。**

**(g) 消融类对照必须配同等规模随机对照。** 内容词消融的 drop 指标**循环**；
人物名消融看似显著但 **82% 的随机对**有同样效应。两者都记为**失败对照**。

**(h) 尺度是必须显式检验的变量（v5，最重要的方法学教训）。**
同一个"雪不成集合"的问题，在 150 词尺度上是"六种表示全部无效应"，
在句子尺度上是"99–100 百分位"。**150 词分析单元有系统性盲区：它会摧毁由单个
句子承载的信号。** 因此：**所有在该尺度上得到的负结果，都必须先在句子尺度
复核，才能作为关于文本的事实报告。**

**(h2) 相似度里有多少只是"用词相同"？——18% / 27%（v13 新增，本轮最重要）。**

### 1.2 文学问题
**(i) 雪的首尾呼应：全篇最强的远距离配对（v7 加强）**

* **句 728**（Mary Jane 引报纸）：
  "They say," said Mary Jane, "we haven't had snow like it for thirty years; and
  I read this morning in the newspapers that **the snow is general all over
  Ireland**."（30 词，字符 63,941–64,101）
* **句 1018**（Gabriel，结尾，para 454）：
  "Yes, the newspapers were right: **snow was general all over Ireland**."
  （11 词，字符 85,028–85,094）

相隔 **290 句**。**两个模型都把这两句判为彼此在全篇 1023 句中的第一近邻**
（MiniLM cos **0.726**、bge cos **0.757**），TF-IDF 也判 1/1。

**匹配对照（v8 新增，回应审稿意见 1）**：原随机对照**不够有力**
（有效样本 <200、只按距离筛选、未匹配句长与词汇重叠、未校正选择效应）。
改用按**距离 + 句长 + Jaccard 词汇重叠**匹配的对照，逐级放宽：

| 匹配强度 | 匹配对数 | 目标百分位（MiniLM / bge / TF-IDF） | 超出匹配均值 |
|---|---|---|---|
| 严格（±25 句、±4 词、±0.05） | 5 | 80.0% / 80.0% / 80.0% | +0.327 / +0.166 / +0.279 |
| **中等（±50 句、±8 词、±0.10）** | **786** | **99.6% / 99.7% / 99.9%** | **+0.438 / +0.272 / +0.398** |
| 宽松（±100 句、±12 词、±0.15） | 17,161 | 100.0% / 100.0% / 100.0% | +0.495 / +0.306 / +0.437 |
| 仅距离（原对照） | 339,076 | 100.0% / 99.9% / 100.0% | +0.535 / +0.317 / +0.481 |

**因为匹配项包含词汇重叠**，这回答的正是"超出字面重复之外还剩什么"：
中等匹配下仍**超出 +0.438**，且目标**不是最大值**（MiniLM 最大 0.757 > 0.726），
不是"对一小批随机值的侥幸胜出"。

**仍然不能声称的（v8）**：该配对是**探索后选出、再受检验**的，所以这是
**事后匹配比较**，不是预注册检验；选择效应无法事后消除。最严格匹配只剩 5 对，
不足以单独支撑推断。因此表述为**"一个计算上极为突出的远距离文本呼应"**——
**不是**"统计上已证明异常"，**不是**"全篇的结构枢纽"。

**NCD 侧**：原始 NCD 抓不到（名次 37,076/420,903），但**长度残差校正后进入
前 0.5%**（2,207/420,903）——**正是长度混淆把这对呼应藏了起来**。

**⚠️ 母题集合检验的定位（v7 修正，审稿意见 4）**：形状匹配零假设下天气集落在
99–100 百分位，**但音乐、宗教、死亡、饮食集也同样达到 ~100%**。因此该检验
**不具区分力**，**不能**支持"雪比其他母题更有组织"。**本轮与雪有关的证据只有
这一条逐字呼应。**

**问题**：**为什么同一句报纸措辞要在第 728 句与第 1018 句各出现一次？**
Mary Jane 复述时用的是现在时、以传闻的口吻（"the snow **is** general"）；
Gabriel 在结尾确认的是过去时、以亲历者的口吻（"the newspapers **were** right:
snow **was** general"）。**同一句话从"别人的传闻"变成"他的确认"**——
这个转换是否就是全篇的结构枢纽？这是一个**可由细读直接检验**的问题。

**(j) 为什么计算方法抓到的是"两个场景 + 一句桥接"，而不是"歌"？**
最稳健的簇由两个子簇构成：**A "听见的时刻"** {54,55,56,58}（Gabriel 仰望楼梯上的
Gretta——"**Distant Music** he would call the picture if he were a painter"——
歌词被听见、歌声骤停、歌名被问出、告辞）与 **B "讲述的时刻"** {69,72,73}
（Michael Furey、Galway、冬天、湿窗、花园、雨、Oughterard 的坟），
**桥接是 unit 69**，全篇唯一同时说出歌与人名的句子。

**歌词替换实验（v9）给出了最直接的答案**：把 unit 55 里那段歌词（恰好是
para 320，18 词）换成别的文本，其余**逐字不动**：

| 变体（18 词） | MiniLM cos(55,58) | 互为近邻 | bge cos(55,58) |
|---|---|---|---|
| **原文歌词** | 0.732 | 1 | 0.817 |
| 比伯《Baby》 | 0.723 | 2 | 0.821 |
| 绿日《Wake Me Up…》 | 0.726 | 2 | 0.812 |
| 爱尔兰民谣《The Minstrel Boy》 | 0.715 | 1 | 0.817 |
| **中性填充（根本不是歌词）** | 0.723 | 2 | 0.824 |
| 原文词序打乱 | 0.713 | 1 | 0.818 |
| **删掉** | 0.707 | 2 | **0.831** |
| *校准：别处的 18 词普通散文* | **0.739** | 1 | **0.838** |
| *校准：换掉 unit 55 的另一个段落* | 0.728 | 2 | 0.815 |

* 等长内容替换只移动 **≤0.019 / ≤0.021**；**原文在两个模型里都不是最大值**；
* 换掉 unit 55 的**另一个**段落只移动 0.004 / 0.002；
* **互为近邻在所有变体、两个模型下都是 1 或 2**；
* NCD 侧等长替换使 d(55,58) 停在 0.776–0.789，校准变体精确复现原文的 d。

**即：该位置的文本内容不参与。** 指标响应的是整个片段（场景、人物、语域），
不是插入的那段文本。删掉歌词的旧结果（Δ = 0.000）由此被**加强并推广**为
"换成任何等长文本、甚至删掉，都不动"。

**替换灵敏度对照（v10 新增，v11 尺度校正）——让这个结果变得有判别力。**
把**同一个替换操作**用在别的对上，看它是否**专门**损伤"共享母题"的那个搭档。

**v11 校正**：v10 用**原始余弦差**比较，有两处尺度不一致——各案例替换量
11%–28% 不等（全局扰动相差约 3.5 倍），且 MiniLM 与 bge 余弦尺度不同。
现改为**尺度无关**度量：计算替换后**全部其他单位**的 Δcos，报告搭档的
**z 分数**与**百分位**；并增加**替换量匹配**模式（各案例都替换固定 18 词）。

| 被替换的段落 → 搭档 | 替换% | MiniLM z | MiniLM 百分位 | bge z | bge 百分位 |
|---|---|---|---|---|---|
| 柠檬水 → 12 | 11% | **−2.84** | **0.0%** | **−2.94** | **0.0%** |
| 啜泣 → 71 | 9% | −1.77 | 0.0% | −1.40 | 6.5% |
| Michael Furey → 69 | 9% | −1.65 | 2.6% | −1.82 | 0.0% |
| Michael Furey → 73 | 9% | −1.09 | 10.4% | +0.28 | 64.9% |
| 歌名 → 55 | 12% | −0.29 | 44.2% | −1.07 | 10.4% |
| **歌词 → 58** | **11%** | **−0.11** | **44.2%** | **−0.70** | **15.6%** |
| 修道士 → 30 | 10% | −0.01 | 48.1% | −1.17 | 14.3% |

**存活的结论**：三个**内容驱动**的对（柠檬水/啜泣/Michael Furey→69）稳稳落在
**0–7 百分位**，与歌词对（**44.2% / 15.6%**）清楚分开——
**方法在 150 词尺度上能感知内容，而歌词对是其中最不敏感的几个之一。**

**⚠️ v11 撤回**：v10 曾称"**(55,58) 是七对里唯一超出量为负的**"。
尺度校正后**不成立**——修道士那一对同样不敏感（z = −0.01 / −1.17），
原来的 +0.010 是噪声。**这同时更正了（30,39）"宗教线"**：
其相似性**不是**由修道士那段内容维系的。
正确表述：**歌词对属于最不敏感的一组（与修道士、歌名同组），而非唯一一对。**

**设计限制**：本检验只替换每对中的**一侧**（A），未替换另一侧；
"整段替换"与"固定 18 词"两种模式的损伤量不同（替换越多损伤越大，排序稳定）。

**替换稳健性（v12）——每案例 30 个供体。**
上面每案例只有**一次**替换，结果可能取决于恰好抽到哪段文本。改为每案例
**30 个不同供体**，并增加第二种替换目标——**"与搭档词汇重叠最高的 18 词窗口"**
（专挑最可能承载链接的那一段拿掉）：

| 替换 → 搭档 | 整段：mean z（MiniLM / bge），受损率 | 最共享 18 词：mean z，受损率 | 判读 |
|---|---|---|---|
| 柠檬水 → 12 | −2.08 / −2.65，93% / 100% | −2.44 / −2.61，97% / 100% | **内容承载** |
| 啜泣 → 71 | −1.71 / −1.71，87% / 97% | −1.76 / −2.01，93% / 100% | **内容承载** |

**② 更正**：v9/v10 的"**该位置的文本内容不参与**"**太强**。换掉歌词会**稳定地**
损伤 (55,58)（MiniLM −0.54、bge −0.96），只是幅度小。
正确表述：**歌词的贡献小且模型间不一致，但不是零**；
**最不敏感的是修道士那对**。

**③ 单次抽样会误导**：单次时 MiniLM 给 −0.11，30 次均值是 **−0.54**——
那一次恰好抽到最温和的供体。**分布纠正了点估计。**

**由此得到的类型学**：**"相似"不是一个东西**，用干预可以把它分成
**内容承载 / 情境承载**两类（外加一个中间带）。而歌簇的两端落在**不同类型**：
**"听见→命名"（55↔58）偏情境，落在中间带；"命名→讲述"（72↔69）是内容承载**，
桥接句 69 在内容那一侧。**簇的两端由不同机制维系**——
这是相似度矩阵里看不到的。

## 2. 既有《死者》细读、叙事学或计算文学研究已经解释了什么？

> 说明：本节是**下一轮需要系统补做文献综述**的位置；此处只写我有把握、
> 且与上面问题直接相关的部分，并明确标出哪些是批评常识、哪些需要引证核实。

**(1) 关于"雪/西行"结尾。** 这是《死者》批评史上最密集的地带：结尾
"journey westward" 与"雪覆盖全爱尔兰"被广泛读作全篇的结构性收束，同时长期
争论这一结尾是真正的"顿悟"还是又一次自我欺骗/瘫痪的确认。
**本轮的贡献**：在句子尺度上，那句"雪遍及全爱尔兰"**确实**是全篇最强的远距离
呼应（互为第一近邻），而且它以**同一措辞、两种时态、两个说话人**的形式出现。
这把"雪是结构中心"从一个阐释判断变成了一个**可核查的文本事实**，
同时给出一个**新的、更精确的问题**（现在时/传闻 → 过去时/确认）。
⚠️ 具体批评家与篇目需在下一轮引证。

**(2) 关于"歌"。** 《The Lass of Aughrim》作为 Gretta 记忆的触发装置是标准读法。
**本轮的发现是：计算方法抓到的不是"歌"这个对象，而是两个场景的配对与桥接句。**
这提示一个可与既有研究对话的点：**批评把"歌"当作枢纽，计算把"那句话"当作枢纽**
——两者是否其实是同一件事的两种描述？

**(3) 关于"引语 vs. 叙述"与自由间接引语。** 《都柏林人》以自由间接引语著称。
候选 1（NCD 与引语密度有关）、候选 4（TextTiling 可能只对"谁在说话"敏感）
与候选 2 的人物名效应都指向同一方向：这些表示在很大程度上测的是**谁在场、
谁在说话**。⚠️ 需引证具体叙事学文献。

**(4) 关于计算文学参照。** Sui et al. (2023) 用**情绪驱动**的表示来分段；
本轮**刻意不用**情绪表示，得到"TextTiling 边界与其他表示正交"。
另外 §1.1(h) 的尺度教训对"母题/意象的计算识别"是一个**通用警告**：
**分析单元的尺度选择可能比方法选择更能决定结论**。

**(5) 关于方法本身。** Hearst (1997) 明确 TextTiling 面向**说明性文本**；
Cilibrasi & Vitányi (2005) 明确区分**实用压缩器**与**理想 Kolmogorov 复杂度**。
候选 1 与候选 4 的"失败"都在原文献的预期之内，本轮把它**量化**了。

**(6) 关于句嵌入的已知问题（v7 修正）。**
v3–v6 引用"形式基线"与句嵌入各向异性的文献相对应。**该对应已撤回**——
替代设计显示句嵌入的相似度**由内容驱动**（r = +0.78），形式只提供高而恒定的
背景。⚠️ 若仍要与各向异性文献对话，需重新设计实验（例如在同一内容、不同句法
的受控材料上测）。

**(7) 关于预处理的可验证性（v7 新增，可引用的方法学点）。**
本轮发现：在带**弯引号**的文学文本上，`nltk.sent_tokenize` 会把约 20% 的
多句块当成一个句子；而"规范化引号"的直觉修法会引入反向错误。
这与计算文学中关于**文本规范化会改变结论**的讨论一致，也为"分句器需要
报告与验证"提供了一个具体案例。⚠️ 需引证具体文献。

### 3.2 遗漏或扭曲了什么

**(1) 扭曲（本轮最大的一个）：分析单元的尺度。** 150 词单元摧毁了单句信号，
使 v4 把一个真实的、极强的结构误判为"不存在"。**这是本报告在 v5 撤回的内容。**

**(2) 扭曲：把"话语层"当成了"内容层"。** 候选 1、4 与候选 2 的人物名效应都
指向：这些表示在很大程度上测的是**谁在场、谁在说话**。

**(3) 扭曲（已修正）：绝对余弦值。** v3–v6 曾称存在约 0.83 的"形式基线"，
所有观察值都在其下方。**该说法已撤回**（占位符假象）。替代设计显示形式相似度
高但几乎不变（0.712），原始余弦的变化由**内容**驱动（r = +0.78）。
**绝对余弦值仍不可跨语料比较，但原因不是"形式基线"，而是内容差异的压缩。**

**(3b) 扭曲（v7 新增）：分析单位的定义本身可能有错。**
v1–v6 的"句子"有 20% 不是句子（分句器错误）。**一个未被验证的预处理步骤
可以使整轮尺度的结论失真**——这比表示或参数问题更隐蔽，因为它不产生报错。
**分句器、切分器、tokenizer 都应视为需要验证的组件。**

**(4) 已修复但仍需说明：截断。** 池化后 0/184；80 词复核仍有 10% 截断。

**(5) 部分解决：单一模型。** v3 引入第二个编码器（矩阵相关 0.671）。
**但只有两个，且都是通用英文编码器。** v4 的消融只在 MiniLM 上做完整，
bge 只做关键项——这是一个**不对称**。

**(6) 未解决：TextTiling 与其他表示的正交性已在两个尺度验证，但只用了两种算法变体。**
v7 复核（修正分句器后）显示正交性在句子尺度保持（**41–53%**）。**该负结果保留**，
但"为什么无关"仍未解释——需要叙事学表示（话语层）来回答。

**(6b) ~~NCD 在句子尺度上是"句式模板检测"~~（v7 撤回）。**
等长分箱检验（17 箱、每箱 ≥25 句）显示：共享对话标签框架的对只在 **9/17 箱**
里更相似，效应量极小。**控制长度后框架不预测 NCD 相似度。**
保留的事实是：NCD 的 50 个最近对平均长度差 **1.4 词**（全体 11.1 词），
即**最近对高度等长**——长度是主因。

**(7) 扭曲：把出版文本的位置关系读成了叙事关系。** 所有"远距离"都是
**文本位置**上的远距离（文档 §5）。

**(8) 未做：真正的"顺序扰动对照"**（文档 §3 指出打乱片段顺序不是有效对照）。

## 4. 下一轮最值得增加的是：新材料、新表示，还是针对候选发现展开细读？

**结论：优先级为 ——（1）把粒度阶梯自动跑到全篇高相似对 →（2）针对"雪的那句话"
展开细读 →（3）把"预处理与对照验证"制度化 →（4）叙事学表示 →（5）新材料。**

v5 的教训是**尺度比方法更能决定结论**；v13 的教训是**干预的粒度同样能决定结论**
（修道士那对：句级 +0.30、整段 −0.06）。因此现在最该做的不是再加案例，
而是**把阶梯变成全篇扫描**——它已经是规则驱动的，没有研究者自由度。

### 第一优先：把粒度阶梯跑到全篇（v13 新增，替换原来的"细读优先"）

理由：本轮的全部结论都建立在**六个手挑的案例**上。阶梯本身已经无自由度
（共享词 = 定义、最共享句 = 定义、人名 = NER、替换词 = 词向量选取），
所以把它跑到**所有**高相似非相邻对上，就能把"承载位置的谱"变成一个
**分布**：

* 多少对在**词级**承载？多少对只在**句级**承载？多少对**没有共享实词**？
* 承载位置与什么相关？（重叠量？距离？位置？）
* **本轮最诱人的一条**：成分分解说"剩余在句子层"。如果全篇扫描确认
  "词级承载只占少数、句级承载占多数"，那就是一个关于**这类方法能看到什么**
  的一般性结论。

### 第二优先：针对"雪的那句话"展开细读

本轮给出了一个精确的、可细读的发现：**同一句报纸措辞以两种时态、两个说话人
出现**，而且它是全篇最突出的远距离配对（**匹配对照已完成**，见 §1.2(i)）。
下一轮应做的：

* 细读句 **728** 与句 **1018** 的**上下文**：Mary Jane 复述报纸的场景（宴会散场前
  的天气闲聊）与 Gabriel 结尾的内心独白，在**人称、时态、叙述层**上的差异。
* 检验"结构枢纽"假说：如果这句话是枢纽，它应该在**叙事学层面**可独立验证
  （例如它是全篇唯一一句被"复述"的句子，或唯一一句跨叙述层重复的句子）。
* 与既有批评对话：**"现在时/传闻 → 过去时/确认"这个转换，既有研究是否已经
  指出过？** 如果没有，这是计算带来的新问题；如果有，计算提供的是**精度**。

### 第二优先：把"预处理验证"制度化（v7 新增）

v7 的教训是：**一个未被验证的预处理步骤可以让整轮尺度的结论失真，而且不报错。**
下一轮应在流程中固定加入：

* **分句器验证**：报告单元数、欠切分与过切分数、偏移回环检验、随机抽样供人工
  阅读（本轮的 `validate_sentences.py` + `spotcheck_sentences.py` 可直接复用）。
* **切分器验证**：任何以"词数/字符数"为单位的切分，都应报告长度分布与边界样本。
* **压缩器的对称性检查**：报告正/反拼接的相关与 top 对重合度。
* **消融实验一律配同等规模随机对照**，并检查该对照是否**饱和**（本轮两种零假设
  设计因此失败）。

### 第三优先：叙事学表示（检验"话语层"假设与桥接功能）

* **话语三层标注**（叙述 / 直接引语 / 自由间接引语），检验候选 1、4 与
  候选 2 的人物名效应是否都归因于**话语层**。这也能解释 TextTiling 正交性的
  来源（它测的是"谁在说话"的切换）。
* **桥接功能的独立检验**：unit 69 是否是全篇唯一同时提及"歌"与"人"的句子？
  可在纯叙事学层面统计，不必依赖嵌入。

### 第四优先：新材料（手稿、书信、校样）

文档 §1 已说明手稿材料"不是本轮实验的前置条件"，§5 明确"出版文本中的位置关系
≠ 创作历史中的时间关系"。**在细读与表示检验完成之前引入手稿材料，
只会增加无法判读的变量。**

## 5. 本轮的边界与可复现性（简）

* **判读边界**：聚类、分段、高相似度 ≠ 文学结构；它们首先是待解释的计算现象。
  **本轮没有把任何无监督输出命名为文学结构**；候选清单每一项都写了替代解释，
  并且**主动撤回了五项**：(2,73)"雪"呼应、"雪不可见"结论、NCD 的"模板检测器"、
  "0.83 形式基线"、"混淆在句子尺度更严重"；**降级一项**（修道院孤立）；
  **改写一项**（歌簇 → 两个场景 + 桥接）。
* **表述的强度必须与证据匹配（v8 的核心教训）**：
  * 探索中选出的配对**不能**与一小批随机配对的最大值直接比较——
    雪的呼应因此从"超过随机最大值"改为**匹配对照下的百分位与超出量**
    （中等匹配 786 对，99.6–99.9 百分位，超出 +0.438），
    并且**仍标注为事后比较、未校正选择效应**；
  * 自动检查的"未发现错误"**只对已定义的检查规则成立**，
    不等于"已证明边界正确"。
* **没有正面发现也是有效结果**，反之**"没有负结果"也需要验证**：
  v5 的教训是**一个看起来很有力的负结果可能是分析单元造成的**；
  v7 的教训是**一个看起来很有力的结论可能是未经验证的预处理造成的**
  （20% 的"句子"不是句子），而这类错误**不产生任何报错**。
* **七个失败/被撤回的对照与结论保留在文档里**：内容词消融的循环指标、
  人物名消融的普遍效应、尺度检验的三种失败零假设（饱和 / 离散度偏差 /
  不具区分力）、v2 关于修道院的过度断言、v6 的"模板检测器"、
  v3–v6 的"形式基线"。**不隐藏。**
* **可复现性**：`../code/` 全部脚本 + `../requirements.txt` + seed=42；
  原文、切分规则、模型名与版本、主要参数、关键数值（JSON/CSV）与图（PNG）
  均已保存。TextTiling 与 NLTK 参考实现的逐位对照见
  `../code/validate_against_nltk.py`（gap 分数最大差 1e-16，边界集合完全相同，
  130 个边界，含 PASS/FAIL 断言）。**分句器**另有独立验证与人工抽查脚本
  （`validate_sentences.py`、`spotcheck_sentences.py`），
  输出 `sentence_validation.txt` 与 `sentence_spotcheck.txt`。
  全部实验脚本均可独立重跑。
