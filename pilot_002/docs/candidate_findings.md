# Pilot 002 候选现象清单 — v1

本清单属于**开放式发现阶段**。候选由全篇统一规则自动产生，没有输入文学标签、
目标词、目标片段或既有批评命题。这里的“候选”只表示跨观察装置复现的原文坐标
关系，不是主题、象征、叙事转折或文学结构。

## 发现总体

- 7 个尺度、22 种尺度—相位切分、5 种表示，共 110 张自相似矩阵；
- 44,653 个未聚合几何事件；
- 按冻结的 1.5% 原文位置容差聚合为 2,144 个坐标候选；
- 几何事件：42,693 `point`、282 `stripe`、588 `block`、1,090 `valley`；
- 原始持久性不低于 0.50 的候选 1,146 个；五表示全覆盖 845 个。

## 必须与候选并列报告的校准

原始持久性存在明显的空间占用基线。保持每张矩阵的事件数量、尺度、相位、表示
与几何类型不变，仅随机重放位置 100 次后，前列位置的零模型平均持久性通常已经
达到约 0.60–0.75。因此：

1. **不能只按原始持久性声称结构稳定**；
2. 2,144 个候选中有 204 个达到单位置经验 `p ≤ 0.05`；
3. 该计数未经多重比较校正，不能称为“204 个显著结构”；
4. 零模型只校准偶然位置重合，不提供文学重要性判断。

完整原排序见 `../results/tables/candidates.csv`；原排序加零模型诊断见
`candidates_calibrated.csv`；零模型审计视图见
`candidates_by_null_calibration.csv`。

## 已暴露的观察装置风险

1. **空间占用会制造共识**：位置随机化证明原始持久性有高基线；零模型是必要的。
2. **NCD 仍受长度主导**：NCD 距离与压缩长度差在句子尺度相关 0.663、段落尺度
   相关 0.702；固定词窗也没有完全消除。五表示共识中的 NCD 支持不能读成
   独立于长度的内容证据。
3. **高持久性不等于文学重要性**：本轮只证明观察器间的复现，不作解释阶段结论。
4. **经验 p 未作多重校正**：它是聚合指标审计，不是总体显著性检验。

## 当前能声称与不能声称的事

可以声称：在冻结规则下，一批原文位置关系跨越多个尺度、相位和表示重复出现，
且前列候选的位置支持高于保持事件密度的位置随机化零模型。

不能声称：这些关系已经构成文学结构；2,144 个候选均有意义；204 个候选统计上
显著；NCD 提供了独立于长度的证据；本轮结果可以推广到其他作品。
