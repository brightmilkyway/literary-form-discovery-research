## 3. 位置随机化零模型

保持每张矩阵的事件数、尺度、相位、表示和几何类型不变，只在合格位置中
随机重放事件 100 次。结果表明原始持久性存在明显的空间占用基线：
前列候选所在位置的零模型平均持久性通常已达到约 0.60–0.75。因此，
**原始持久性不能单独解释，必须与位置零模型一起报告。**

- 单候选经验 p ≤ 0.05：204 / 2,144；
- 该计数未经多重比较校正，不作为显著性发现数量；
- 它只用于识别哪些位置的跨装置支持明显超过相同事件密度下的偶然重合。

## 6. 判读边界

1. 排序在读取候选正文前完成；预览只用于可追溯性。
2. 聚合容差与阈值来自预先冻结的 `protocol.md`，本报告没有按结果调参。
3. 高持久性表示跨观察装置复现，不自动等于文学重要性。
4. 低持久性不表示原文关系不存在，只表示本轮观察器未稳定恢复它。
5. 本轮不以 Pilot 001 的定向候选验证成功与否作为成败标准。
6. 零模型经验 p 是未校正的探索性诊断，不是文学重要性或总体显著性。
7. NCD 的明显长度混淆被保留并报告，不能用其支持单独作结构解释。

## 8. v2 严格拓扑：连通岛稳健，环不稳健

本节属于开放式发现阶段，但不沿用 v1 的“持久性”含义。v2 对远距离上三角
相似度景观做二维 cubical filtration，在 `F2` 上计算 `H0/H1`，分析视野为
`alpha <= 0.25`。每张矩阵同时置换行列中的文本单元 100 次：全部两两相似度
保持不变，只破坏其阅读顺序。经验 p 为双侧，110 张矩阵分别作 BH 校正。

| 拓扑量 | 未校正双侧 p ≤ .05 | BH q ≤ .05 | 平均 z | 现行结论 |
|---|---:|---:|---:|---|
| `H0` 总持久度 | 94 / 110 | **94 / 110** | **−4.430** | 稳健低于顺序置换零模型 |
| 强 `H0` 条数（寿命 ≥ .05） | 91 / 110 | **91 / 110** | **−3.848** | 稳健更少 |
| 最长 `H0` | 0 / 110 | **0 / 110** | −0.241 | 没有单一异常巨峰 |
| `H1` 总持久度 | 19 / 110 | **0 / 110** | +1.154 | 未校正迹象，校正后撤回为候选 |
| 最长 `H1` | 4 / 110 | **0 / 110** | +0.314 | 不支持稳定环 |
| 强 `H1` 条数 | 15 / 110 | **0 / 110** | +0.961 | 不支持稳定环 |

`H0` 结果的方向是**赤字**：原文顺序中的高相似岛更少、总寿命更短，但单个最长
寿命不异常。与随机重排同一批两两相似度相比，文本中的相似关系更倾向于靠近并
较早合并，而不是散成许多孤立峰。这个方向在 100–200 词窗最强；句子尺度五张
矩阵均未通过 `H0` BH，说明它是区域级组织，不是精确句对的普遍性质。

表示差异同样保留：`H0` 总持久度平均 z 在字符 TF-IDF / 词 TF-IDF 为
−6.33 / −6.30，在 MiniLM / BGE 为 −2.98 / −2.70，NCD 为 −3.83。词法表示
最强，但五种归纳偏置总体同向；NCD 的长度混淆仍使其只能作为敏感性观察器。

反复出现的 `H0` birth cell 与 v1 固定阈值几何独立汇合：前十个坐标簇全部匹配
回 v1 候选。前两项分别是：

1. 5625 ↔ 9225（31 张矩阵、6 尺度、4 表示）→ v1 C0002；
2. 5187.5 ↔ 14150（24 张矩阵、5 尺度、4 表示）→ v1 C0001。

这表明 v1 的 block/stripe 前列关系也构成 filtration 中长寿的高相似连通岛，
不是只在 97.5% 固定阈值处出现。birth cell 只是同调类的出生坐标，不是完整
代表循环或区域边界。

`H1` 的正向迹象集中在 100–150 词及词法表示，且坐标首项位于作品后段；但
19/110 个未校正结果在 BH 后全部消失。因此本轮**不能声称存在稳定拓扑环、叙事
循环或循环结构**。这些坐标只保留为下一轮候选，不进入现行正面结论。

拓扑结论也不改变 v1 的七个谷或 2,144 个坐标候选排序；它回答的是阈值连续变化
下的全局连通方式，而不是重新给候选赋予文学名称。
