# Pilot 002 — 无文学标签的多尺度结构持久性探索

## 0. 研究性质与冻结边界

本轮是探索性研究，但发现规则在查看结果前冻结。研究对象仍为 James Joyce 的
*The Dead* 英文正文。Pilot 001 的定向词表、人物案例和文学命名不进入发现程序。

本轮把“纯粹探索”操作化为：

1. 不输入主题、象征、人物功能、叙事层次或既有批评命题；
2. 不指定 snow、song、death、religion 等目标词或目标片段；
3. 不根据输出临时选择尺度、切分起点、表示或阈值；
4. 所有候选都由全篇统一规则产生并映射回同一原文坐标；
5. 自动发现完成前不以候选内容决定保留或删除；
6. 文学命名不属于本轮的计算结论。

“无标签”不等于“无先验”。分词、切分、距离函数、编码器与阈值都是明确记录的
观察装置。本轮研究的正是：一个候选对这些装置是否具有持久性。

## 1. 核心问题

> 在不使用文学标签和目标案例的条件下，*The Dead* 中哪些内部关系能够跨越
> 分析尺度、切分相位与文本表示持续存在？这些关系在自相似矩阵中呈现何种
> 几何形式？

四个子问题：

1. **多尺度持久性**：同一原文区域关系能在多少分析尺度上重现？
2. **切分相位稳定性**：关系是否随固定词窗起点移动而消失？
3. **矩阵几何**：结果是孤立点、顺序保持的条带、区域块，还是低相似断裂？
4. **多表示共识**：归纳偏置不同的观察器是否独立恢复同一关系？

## 2. 统一坐标

所有单元保存：

- 正文字符区间 `[char_start, char_end)`；
- 正文词序区间 `[word_start, word_end)`；
- 中心词位置；
- 来源尺度、窗口长度与相位。

跨运行比较只使用原文词坐标，不比较各切分内部的 unit 编号。

## 3. 冻结的分析尺度与相位

### 3.1 文本内生单位

- `sentence`：沿用 Pilot 001 经修正的“先段落、再段内 Punkt”分句；
- `paragraph`：原文空行定义的段落。

### 3.2 固定词窗

- 窗长：50、100、150、200、300 词；
- 非重叠窗口；
- 相位：窗口长度的 0%、25%、50%、75%（向下取整）；
- 末尾不足窗口 25% 的残片丢弃。

相位只改变观察网格，不改变原文。句子和段落没有相位。

## 4. 冻结的五种表示

1. `char_tfidf`：字符 3–5 gram TF-IDF 余弦；
2. `word_tfidf`：词级 1–2 gram TF-IDF 余弦；
3. `ncd`：zlib 的双向平均 NCD，转为相似度；同时记录长度相关；
4. `minilm_white`：`all-MiniLM-L6-v2`，在《都柏林人》其他十四篇的同尺度
   单元上拟合 ZCA 白化；
5. `bge_white`：`BAAI/bge-small-en-v1.5`，使用相同的外部拟合规则。

神经表示以段落感知的子块池化避免截断。白化只在其他故事上拟合，不能使用
*The Dead* 自身估计几何变换。原始神经余弦只作诊断，不进入五表示共识率。

## 5. 非局部联系与标准化

一对单元只有在两个区间之间的正文词距至少为 `max(300, 0.03 * 全文词数)` 时，
才进入远距离候选池。这一规则用原文坐标定义，因此不随尺度改变。

每张矩阵内部把合格配对按相似度转换为经验百分位。不同表示只比较百分位，
不比较原始数值。

## 6. 候选几何与阈值

阈值在运行前固定：

- **point**：远距离配对百分位不低于 99%；
- **stripe**：矩阵中沿平行于主对角线方向连续至少 3 格、且每格不低于 97.5%；
- **block**：97.5% 阈值二值图中的八邻域连通成分，至少 6 格，并且两个轴
  都覆盖至少 2 个单元；
- **valley**：每个内部边界左右各取 3 个单元，跨边界平均相似度处于该矩阵
  所有可比较边界的最低 5%。

几何事件先在单张矩阵内产生，再映射回原文词坐标。

## 7. 跨运行聚合

两个 `point/stripe/block` 事件若两端中心位置分别相差不超过全文词数的 1.5%，
归入同一候选簇；A/B 顺序按阅读顺序固定。`valley` 按边界位置以同样容差聚合。

每个候选报告：

- `scale_coverage`：出现过的尺度数 / 7；
- `representation_coverage`：出现过的表示数 / 5；
- `phase_coverage`：在曾检出该候选的词窗尺度中，出现过的相位数 / 可用相位数；
- `support_events`：独立矩阵事件数；
- `best_percentile` 与中位百分位；
- `persistence`：前三项覆盖率的几何平均；
- 原文区间、位置误差和不参与筛选的短预览。

候选排序首先按 `persistence`，再按 `support_events`。正文预览只在排序完成后附加。

## 8. 必须输出

1. 所有切分单元及统一坐标；
2. 每张自相似矩阵及元数据；
3. 未聚合的几何事件表；
4. 聚合后的候选表；
5. 尺度—位置图、表示共识图、代表性矩阵几何图；
6. NCD 长度诊断、神经表示白化拟合来源和运行日志；
7. 一份不作文学命名的结果报告。

## 9. 成功、负结果与停止条件

第一轮在满足以下条件后停止，不因结果“不够文学”继续加模型或调阈值：

- 七种尺度和四种词窗相位全部生成并通过坐标回环检查；
- 五种表示均成功运行，或明确记录真实的环境阻断；
- `point` 与 `stripe` 至少完成算法级提取；
- 每个候选可追溯到原始矩阵和原文坐标；
- 输出全部候选，包括不稳定、单表示和低共识结果；
- 记录参数敏感性风险，但不在本轮根据结果改动冻结阈值。

没有高持久性候选是有效结果：它意味着所谓结构依赖观察装置，不能包装成
“作品没有结构”。

## 10. 与 Pilot 001 的关系

Pilot 001 提供原文、可靠分句、编码器池化、外部《都柏林人》材料和白化实现。
Pilot 002 可以复用这些经验证的基础设施，但不得读取 Pilot 001 的主题词表、
定向候选列表或文学判词来生成候选。

## 11. 首次冻结运行后的零模型诊断（不修改发现规则）

首次完整运行产生了大量高覆盖候选。为区分真实的跨观察器位置共识与“事件多、
空间分箱有限”造成的偶然重合，追加一个**只作校准、不反向改阈值**的零模型：

- 保持每张矩阵的事件数、几何类型、尺度、相位和表示不变；
- `point/stripe/block` 在该切分所有合格远距离单元对中随机重放位置；
- `valley` 在该切分所有内部边界中随机重放位置；
- 使用相同的 1.5% 坐标分箱和持久性公式；
- 固定随机种子 42，重复 100 次；
- 对每个已观察分箱报告零模型持久性的均值、支持矩阵均值和经验 p 值。

该诊断是对聚合指标是否饱和的审计。即使零模型否定了当前持久性排名，首次运行
仍原样保留；不得删除“不显著”的候选或据此回调发现阈值。
