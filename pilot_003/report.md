# Pilot 003 实验报告

## 1. 完成状态

2026-10-29 已完成三个响应维度的首轮端到端实验：

- 表示响应：2 种固定哈希方法 × 3 种文本尺度 × 40 个检查点；
- 预测响应：DistilGPT2 对正文 22,575 tokens 中 22,574 个可预测 token 的 surprisal；
- 解释响应：DeepSeek 官方 `deepseek-flash` 对 40 个前缀执行 2 个完全相同的重复轮次。

输入文件 SHA-256 为
`13284c0070a518ed4f4c7d5cc857bc2bcdc11f229c3e042cc22e593c570a9f2d`（规范化换行后）。剥离标题后
正文含 85,683 字符、15,732 个规则词和 455 个空行定义的自然段。40 个检查点从
首段覆盖至末段；相邻点相隔 11 或 12 段，但词覆盖增量介于 0.0083 和 0.0601。

本轮没有人工恢复事件、情节或主题，也没有根据输出峰值修改检查点和主要指标。

## 2. 表示响应

相邻余弦距离的结果如下。p 是与 500 次随机检查点顺序的双侧经验比较，只作诊断。

| 方法 | 对象 | 均值 | SD | 最大位置 | 随机顺序均值 | 双侧 p |
|---|---:|---:|---:|---|---:|---:|
| char hash | p1 | 0.8915 | 0.0864 | cp_031 | 0.8958 | 0.6387 |
| word hash | p1 | 0.9175 | 0.0779 | cp_013 | 0.9215 | 0.6986 |
| char hash | p4 | 0.6565 | 0.1245 | cp_032 | 0.6666 | 0.2355 |
| word hash | p4 | 0.7187 | 0.1154 | cp_032 | 0.7327 | 0.1517 |
| char hash | cumulative | 0.0074 | 0.0322 | cp_002 | 0.0309 | 0.0040 |
| word hash | cumulative | 0.0090 | 0.0370 | cp_002 | 0.0398 | 0.0040 |

字符与词轨迹在 `p1`、`p4`、累计尺度上的 Pearson r 分别为 0.914、0.960、1.000，
说明两个表面特征观察器在相对变化上高度一致。但累计前缀的显著平滑首先来自嵌套
输入：两种累计表示各有 36/39 次距离低于 0.01，最大值都出现在最早的 `cp_002`。
这不能解释为“理解逐渐稳定”。

`word_hash/p1` 有 10/39 个距离饱和到 1.0，字符方法为 2/39；单段词特征的最大峰
因完全无词 n-gram 重叠而不稳定。`p4` 没有饱和值，但本轮没有据此替换冻结指标。

## 3. 预测响应

实际模型为 `distilbert/distilgpt2`，仓库 revision
`2290a62682d06624634c1f46a6ad5be0f47f38aa`，tokenizer 为
`GPT2TokenizerFast`。CPU 推理耗时 211.66 秒；最大上下文 1024、步幅 512。除正文
首 token 外，每个 token 都保存字符区间、实际历史长度和 nats/bits surprisal。

全篇 token surprisal 均值为 3.4966 nats，SD 3.0465，中位数 2.7775，90 分位
7.8214，最大 20.2516。检查点区间均值最高的是 `cp_001`（4.1958），其后为
`cp_015`（3.8949）、`cp_033`（3.8786）、`cp_010`（3.8496）和 `cp_040`
（3.8469）；最低为 `cp_031`（2.1171）。

这些区间样本量从 158 到 1,186 tokens 不等，且 `cp_001` 的上下文从 1 token 起步，
不能把最高区间直接解释为作品开头更“令人惊讶”。检查点均值还混合了段落长度、
词汇频率、模型年代与 512-token 滑窗边界等效应。当前 surprisal 是 DistilGPT2 的
计算响应，不是人类阅读难度或情绪。

## 4. 解释响应

两轮共执行 80 次官方 API 调用，响应模型字段均为 `deepseek-flash`，后端指纹均为
`bc19ba97cbe016479903222bb1578db6`。第一轮使用 420,602 输入和 10,747 输出 tokens；
第二轮为 420,602 输入和 10,716 输出 tokens；总计 862,667 tokens。缓存命中
454,141 tokens，未命中 387,063 tokens。所有响应均正常停止、通过 JSON schema，
完整原始输入、输出、response ID、指纹和用量均已保存；密钥没有落盘。

固定提示要求 120–180 个英文词，但两轮平均分别为 188.45 和 186.45 个词，每轮仅
12/40 个输出合规。这是明确的提示遵循失败，不能因为内容可用而忽略。

用同一固定词 1–2 gram 哈希比较完整三字段输出：相邻检查点平均距离为 0.2875，
同一检查点两轮平均距离为 0.2575。重复噪声与序列变化处在相近量级，因此单轮曲线
中的局部峰值不够稳定。两轮相邻距离轨迹的 Pearson r 仅为 0.511；39 次转移中，
两轮平均相邻距离有 74.4% 高于目标检查点的跨轮距离，但仍非清晰分离。最高同点
重复距离出现在 `cp_040`（0.4148）和 `cp_006`
（0.4015）；第一轮最大的相邻变化是 `cp_039→cp_040`（0.4106），第二轮同一转移为
0.3612。模型温度为 0 仍未产生确定性文本。

## 5. 三维度对齐

把 39 次转移对齐后，以预测区间均值的绝对变化、`p4` 表示距离和两轮解释距离均值
作探索性相关。字符/词表示之间仍高度一致（Spearman rho=0.939）。预测变化与字符、
词表示的 Pearson r 分别为 0.459 和 0.409，但 Spearman rho 仅为 0.295（p=0.069）
和 0.213（p=0.193），说明线性相关可能受少数大变化驱动。

预测变化与解释变化的 Spearman rho 为 -0.112；字符、词表示与解释变化分别为
-0.240 和 -0.250。所有跨维度检验均未校正多重比较，且解释重复噪声很大，不能据此
宣称三个响应维度共享同一个潜在文学结构。当前更可靠的观察是：两个表面表示方法
彼此一致，但解释响应没有稳定复制这种顺序轨迹。

## 6. 失败案例与稳健性

1. **累计表示机械退化**：共享历史使距离快速趋零，是负面对照而非稳定理解证据。
2. **短段稀疏饱和**：`p1` 词表示多次距离为 1.0，单峰排序缺乏区分力。
3. **检查点长度不齐**：词增量最多相差约 7.2 倍，三类局部摘要都可能受长度影响。
4. **解释提示长度失守**：JSON 全部合格，但仅 30% 输出满足词数约束。
5. **温度 0 不确定**：同点重复距离接近相邻距离，局部解释峰不具备单轮可信度。
6. **预训练熟悉不可排除**：prefix-only 限制显式正文输入，不保证 DeepSeek 未见原作。
7. **预测模型局限**：DistilGPT2 体量小、上下文短、训练分布较旧；滑窗分块使不同
   token 获得的历史长度不完全相同。
8. **基线仍有限**：表示顺序置换不保持局部长度；预测与解释尚无长度匹配零模型。
9. **相关是事后探索**：未作多重比较，也不能从低相关推断认知系统彼此独立。

## 7. 结论与下一步

Pilot 003 已证明三类响应可以在不恢复事件的前提下产生可追溯、可重复运行的序列
数据。但“稳定序列结构”的证据目前只在共享表面偏置的字符/词表示之间较强；累计
平滑是设计效应，解释曲线的重复噪声较大，预测变化与其他维度的秩相关较弱。

下一步最有价值的不是解释峰值，而是建立长度匹配的块置换零模型；增加一个不同
架构的因果语言模型；把解释输出长度改为机器可验证 schema 后作为新协议重复，而非
覆盖本轮失败；并在有人类阅读数据之前继续避免使用“认知事件”“惊讶”或“文学
转折”等命名。
